L’application mobile Djaber (Android et iOS) reprend votre espace : boîte de réception, commandes, livraison, clients, stock, agents et statistiques, avec les notifications push. Elle utilise le même compte que le web.

## Installer et se connecter

- Téléchargez l’application : ⟦À COMPLÉTER : liens Google Play et App Store⟧.
- Connectez-vous avec le même e-mail et le même mot de passe que sur le web ; si la double authentification est activée, saisissez votre code.
- Si vous avez plusieurs espaces, changez d’espace depuis l’application.
- Après la première connexion, l’application propose le déverrouillage par empreinte ou Face ID. Vous pouvez l’activer ou le couper dans Compte › Sécurité.

## Ce qui se fait uniquement sur le web
L’application affiche ces éléments avec la mention « Uniquement sur le web » :

- membres et invitations (accepter une invitation fonctionne sur mobile) ;
- intégrations : Google Sheets, clés API, webhooks ;
- modification des messages système ;
- changement de plan, paiement, factures et codes promo d’abonnement ;
- activation ou désactivation de la double authentification et codes de secours ;
- zone de danger : suppression de l’espace, transfert de propriété ;
- rapports programmés et création de vues enregistrées ;
- exports de rapports volumineux (XLSX / PDF).

## Crédits sur mobile
Les packs de crédits s’achètent dans l’application, par Google Play ou l’App Store, au prix affiché par le store. Les crédits sont ajoutés après vérification de l’achat par Djaber ; « Restaurer les achats » renvoie un achat non terminé. Le changement de plan et le paiement de l’abonnement se font sur le web.

## Supprimer mon compte
Compte › « Supprimer mon compte », avec votre mot de passe. Si vous êtes propriétaire d’un espace, transférez-le ou supprimez-le d’abord depuis le web.
