Djaber répond à vos clients sur Messenger et Instagram avec un agent IA, prend leurs commandes et vous les remonte dans l’application. Pour démarrer, il vous faut un produit, un agent et une page connectée.

## La configuration guidée
À la création de votre espace, une configuration guidée s’ouvre. Chaque étape est facultative et votre progression est enregistrée : vous pouvez la quitter et la reprendre plus tard.

- Bienvenue : le résumé des étapes, puis « Commencer ».
- Stock : choisissez le mode « Simple » (produits avec leurs variantes, commandes, clients, livraison) ou « Avancé » (en plus : prix de revient et marges, fournisseurs, achats, ventes au comptoir, caisse, inventaires, rapports). Cela ne change que l’interface, sur le web et sur mobile ; vous pourrez changer à tout moment dans Paramètres › Mode stock.
- Produit : votre premier article (nom, prix, stock, photo). Voir le guide « Ajouter votre premier produit ».
- Agent : un des modèles prêts à l’emploi (Vendeur Pro, Service Client, Conseiller Produit, Réponse Express) avec « Utiliser cet agent », ou « Partir de zéro (assistant guidé) ».
- Page : « Continuer avec Facebook » ou « Continuer avec Instagram ». Votre e-mail doit être vérifié pour connecter une page.
- Prêt : ce qui est fait et ce qu’il vous reste à faire, avec « Tester mon agent », « Importer mon catalogue », « Inviter mon équipe » et « Aller à l’accueil ».

## Passer ou reprendre la configuration
« Passer la configuration » vous demande une confirmation, puis vous amène sur l’Accueil. Le propriétaire de l’espace peut relancer la configuration guidée depuis Paramètres › Espace de travail › « Reprendre la configuration ».

## La liste « Démarrer » de l’Accueil
Sur l’Accueil, la liste « Démarrer » se coche d’elle-même à partir de vos vraies données :

- « Connecter une page » : au moins une page active ;
- « Ajouter des produits » : au moins un produit actif ;
- « Configurer votre agent IA » : au moins un agent actif relié à une page ;
- « Réalisez votre première vente » : une première commande livrée ou une première vente.

## Et ensuite
Testez votre agent dans le bac à essai avant de l’activer (guide « Configurer votre agent IA »). Les commandes prises par l’agent arrivent dans Commandes, avec un appel de confirmation à passer.
