title: Sécuriser votre compte : mot de passe, 2FA et sessions
---
Paramètres › Sécurité réunit votre mot de passe, la vérification en deux étapes (2FA) et la liste des appareils connectés. Activez la 2FA : sans votre téléphone, un mot de passe volé ne suffit plus pour entrer.

## Activer la vérification en deux étapes
- Installez une application d'authentification sur votre téléphone (Google Authenticator, Authy…).
- Dans Paramètres › Sécurité, section « Vérification en deux étapes (TOTP) », cliquez sur « Activer ».
- Scannez le QR code (ou saisissez la clé), puis entrez le code à 6 chiffres affiché par l'application.
- Djaber vous donne 10 codes de récupération : « Télécharger les codes », gardez-les en lieu sûr, cochez « J'ai enregistré mes codes de récupération » puis « Terminer ».

À chaque connexion, Djaber vous demande ensuite le code de l'application. Sans votre téléphone, choisissez « Utiliser un code de récupération » : chaque code ne sert qu'une fois. « Régénérer les codes » invalide les 10 anciens codes. Le code 2FA est aussi demandé pour les actions sensibles, comme transférer la propriété de l'espace ou supprimer votre compte.

## Changer de mot de passe
Saisissez le MOT DE PASSE ACTUEL et le NOUVEAU MOT DE PASSE (8 caractères au minimum, au moins 1 lettre et 1 chiffre), puis « Changer ». Les autres appareils sont déconnectés.

## Sessions actives
SESSIONS ACTIVES liste les appareils connectés à votre compte. Déconnectez un appareil inconnu, ou choisissez « Déconnecter tous les autres appareils » : ils devront se reconnecter avec le mot de passe (et la 2FA). Votre session actuelle reste ouverte.

## Bons réflexes
- Ne partagez jamais votre mot de passe : invitez plutôt chaque personne de l'équipe avec son propre compte (Paramètres › Membres).
- Si vous pensez qu'on a utilisé votre compte, changez le mot de passe puis déconnectez tous les autres appareils.
