A saved view keeps the search, tab, filters, sort, columns and density of a list, so you get it back in one click. It exists on the Orders, Delivery, Products, Clients, Sales, Purchases, Cash register, Movements and Agents lists.

## Save a view
- Set up the list: tab, “Filters”, search, sort, columns.
- Open “Views”, then “Save the current view…”.
- Give it a name, for example “To send Sétif”. Tick the option to open the list on this view by default if you want it each time you open the list.

Filters are also written in the page address: copy the link to get exactly the same list back.

## Manage your views
In “Views”, the menu of each view offers rename, “Set as default” (or remove the default), duplicate and delete. Two views of the same list cannot have the same name. Deleting a view changes no data of the list.

## Share a view with the team
The owner and the admins can choose “Share with the team”. A shared view is offered to the whole team, marked SHARED; the others cannot change it, they can only duplicate it into their own copy. Only its author renames it, stops sharing it or deletes it; once deleted, it disappears for everyone. Your default view applies to you only.
