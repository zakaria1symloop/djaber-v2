- Page: /fr/settings/billing?change=free&cycle=monthly, reached from /fr/pricing › Gratuit › « Choisir ce plan » while signed in (owner, trial Pro, fr, 1440 px)
- Severity: Minor
- Type: Bug

- Expected: the deep link follows the card. The card is greyed with the reason « Vous êtes en essai : le plan gratuit s'appliquera automatiquement le 02 déc. 2026, sauf si vous choisissez un plan payant. », so no change-plan dialog opens (or the dialog only says that reason). No promo field and no « Payer » button for a 0 DA plan.
- Actual: « Changer de plan · Pro (essai) → Gratuit · Mensuel · 0 DA / Annuel · 0 DA », a red error box « Aucun paiement requis pour ce plan. » (`POST /billing/preview` → 422 `PLAN_IS_FREE`), « CODE PROMO … Appliquer », and a greyed « Payer … DA (CIB / Edahabia) ».
