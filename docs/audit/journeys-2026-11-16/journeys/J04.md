### J04-2 — The reply language is guessed from the last message alone: « Bonsoir » → English; a phone, a name or an address flips the conversation (English recap to an arabizi customer, French recap to an English one)
- Page: playground dialog (owner, fr / en, 1440) + shared test link (visitor, fr)
- Severity: Major
- Type: Bug
- Steps: 1. First message « Bonsoir » (P15 playground, O06 shared link). 2. O01 (fr): « Samira Benali » then « 0661234567 ». 3.
