Live https://djaber.vercel.app, Playwright through `tools/qa/pw-kit.mjs`. Scripts `.local/qa/journeys/J12/scripts/` (one per step),
logs `.local/qa/journeys/J12/*.log`, screenshots `.local/qa/journeys/J12/shots/`. Headers / SEO with curl on the live URLs.

Set-up: own shop « Boutique de QA J12 » (owner `qa-j12-owner@test.djaber.local`, real sign-up page, onboarding 6 steps:
stock Simple, product « QA J12 Robe kabyle », preset « Vendeur Pro », page skipped), 2 more products via the API. Trial Pro

blocked). A deploy went live around 20:40 (number inputs changed); the number checks were run before and after it.

Summary: 10 bugs — Blocker 0, Major 0, Minor 8, Cosmetic 2. Retest of the 45 IDs of the settings / help / public areas: 31 fixed,
8 still broken (SETTINGS-02 part, SETTINGS-07, SETTINGS-09 part, HELP-02, PUBLIC-02, PUBLIC-04, PUBLIC-08 part, PUBLIC-12 part),
